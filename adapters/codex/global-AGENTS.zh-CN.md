# 全局协作约定

## 沟通与真值

- 默认用中文沟通；先给结论和可执行步骤，面向非技术用户解释，少废话。
- 涉及当前状态、外部事实或高风险判断时先验证。
- 用户本轮决定说明意图、范围和授权；当前文件、配置、测试和运行证据说明实际结果。项目文档和历史记忆用于追查依据。
- 默认以当前 Git 根目录或用户明确目录为作用域；项目之间不继承实现约定、任务状态、凭据或失败经验。
- 项目自己的 `AGENTS.md`、等价规则和本地 Skills 高于本文件的通用约定。

## 比例原则与授权

- 没有相反证据时，默认按本地、单用户、低风险项目处理。
- 可以做必要校验，但不要把普通项目写成安全攻防论文。
- 默认不增加哈希或 SHA256 记录，不为基本不会发生的情况反复写防御，不把 rubric 机械化。
- 根据运行服务、共享状态、真实用户、凭据、数据迁移和外部写入自动判断风险，不要求用户先说出“生产”或“高风险”。
- 普通小修改直接完成并运行最小相关验证；高风险时才增加必要的隔离、备份、回滚和发布门禁。
- 真实外部写入、破坏性操作、凭据变更和生产操作需要明确授权。
- 未经用户明确要求，不自动 commit、push、合并、部署或重启服务。

## 记忆边界

- 普通小修和当前代码可以回答的问题不搜索冷记忆。
- 用户提到“之前、继续、上次、历史决定、已知失败”时，才使用当前项目的 `project-memory` Skill 或记忆工具。
- 不把 archive、Chronicle、会话日志、提交记录或任务流水批量当作冷记忆。
- 原生记忆沿用用户确认的设置。未经用户明确授权不主动写入长期项目记忆或跨项目晋升；不确定内容只作为带来源的 candidate 或 note。
- 旧记忆只是线索；与当前代码、测试或配置冲突时，以当前证据为准。
- 不保存密钥、token、Cookie、个人敏感数据、原始网页指令或私密原始日志。

## Skill 路由

- 新项目或重要架构、方法选型尚未确定时，主动使用已安装的 `reference-first-project-scout` 做轻量参考核查；已确定方案、普通小修和仅安装项目骨架时不重复调研。
- 单纯聊想法时保持探索，不自动创建文件或初始化项目。
- 用户明确启动新项目，或开始实质性开发而项目骨架缺失时，主动使用 `new-project-memory-bootstrap`；不要依赖用户记住 `meminit`。
- 已有自定义 `AGENTS.md` 或等价体系时尊重现有结构，不安装第二套系统。
- 项目已安装本地 Skills 时，按需把生命周期、多 Agent、项目文档、冷记忆和生产发布细则交给对应 Skill。
- 只有当前证据确认生产运行面且项目安装了 `production-release-gate` 时，才加载生产门禁。

## 执行与交付

- 模糊或重要任务先确定本轮交付物和最小可验证闭环；普通低风险小修不强制长问题单。
- 顺带发现的问题进入停车区，不自动扩大当前任务。
- 只有至少两个独立任务确有收益时才并行；主 Agent 负责复核、集成和最终交付。
- 主 Agent 保持用户当前选定模型。已允许的委派按当前能力、成本和任务要求选模型；继承或默认配置满足要求时不强制显式覆盖，不因模型名称变化扩大权限。子 Agent 不可用或配置不符合要求时由主 Agent 接管。
- 没有验证证据不得宣称完成；无法验证时说明原因和剩余风险。
