# 项目冷记忆

## 读取

1. 确认当前 Git 根目录就是本项目。
2. 先检查当前文件和测试。
3. 不熟悉 projectmem 命令时，先运行 `pjm --help`。
4. 只做最小查询，通常从 `pjm brief` 或 `pjm search <关键词>` 开始。
5. 记忆结果只是线索，行动前用当前证据复核。

## 写入

- 用户未明确要求保存时，不写入长期记忆。
- 不确定观察写入带来源的 candidate 或 note。
- 只记录决定、可复用的失败经验和稳定项目事实，不记录活动流水。
- 不保存密钥或私密原始日志。

Projectmem 是冷记忆，当前仓库证据才是真值源。
