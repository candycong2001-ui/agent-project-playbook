## 已知上限

- `codex exec --json` 的事件没有返回模型字段；默认 Sol 由已解析配置和未传 `--model` 的新进程 smoke 共同验证，不是运行事件直接回报的模型名。
- 没有故意省略子 Agent 模型来测试 Terra 兜底，因为运行协议要求每次派发显式选择模型。
- 当前 CLI 的 `--strict-config` 被全局配置中既有的 `[network]` 字段阻塞；普通配置加载成功，该字段不属于本次适配修改。
- 没有验证其他账户、操作系统、Codex 版本、WorkBuddy、Claude Code 或其他 Agent 平台。

因此 v0.2.0 的兼容性状态是“本机有限验证”，不是“所有 Codex 环境完整支持”。
