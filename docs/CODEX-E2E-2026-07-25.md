# Codex E2E 验证记录（2026-07-25）

## 结论

Codex 省心模式在本机完成有限 E2E smoke：

- 新 Codex CLI 进程可以正常加载全局配置。
- `gpt-5.6-sol` 可以作为独立主模型启动。

本记录只证明下述环境和检查，不代表其他账户、Codex 版本或 Agent 平台自动兼容。

## 已知上限

- `codex exec --json` 的事件没有返回模型字段；默认 Sol 由已解析配置和未传 `--model` 的新进程 smoke 共同验证，不是运行事件直接回报的模型名。
- Terra 兜底负路径尚未验证：运行协议要求每次派发显式选择模型，且当前事件不暴露子 Agent 的实际模型，不能把无法审计的自报结果算作 PASS。
- 当前 CLI 的 `--strict-config` 被全局配置中既有的 `[network]` 字段阻塞；普通配置加载成功。隔离配置的排障方法见 [Codex 适配层](CODEX-ADAPTER.zh-CN.md#严格配置排障)。
