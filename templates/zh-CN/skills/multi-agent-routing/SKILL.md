# 多 Agent 路由

## 委派判断

- `NO_DELEGATION` 是正常结果；任务很小、线性、立即阻塞或验收成本高时，由主 Agent 直接完成。
- 只有任务相互独立、所有权清楚、并行有实际收益且容易复核时才委派。
- 用户只保留一条主对话；主 Agent 负责范围、冲突、集成、验证和最终交付。

## Worker 契约

1. 明确有边界的目标、负责文件或范围、预期产物、所需证据和停止条件。
2. 能力与推理深度按任务选择；更强推理不会获得更宽权限。
3. Worker 不继续创建 Worker，也不扩大范围；证据冲突和更高风险操作交回主 Agent。
4. 主 Agent 用当前文件、测试或真实输出复核关键结论后才能采纳。
5. 部署、删除、凭据、外部写入和最终 Git 交付继续由主 Agent 复核，并在需要时取得用户授权。
